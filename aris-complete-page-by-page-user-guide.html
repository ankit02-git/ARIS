Dashboard

/dashboard
Research ka overview — pehli nazar mein apni progress aur stats dekhne ki jagah.

Kya Dikhai Deta Hai

  • Papers collected (total database mein)
  • Saved papers (aapki library)
  • Papers analyzed (processed count)
  • Research activity status
  • Recently saved 5 papers
  • Quick search bar

Quick Actions

  • Search Papers → Explore page
  • My Library → Library page
  • Analytics → Analysis page
  • AI Assistant → Chat page

✅ Best Use Tips

  • Dashboard pe aate hi recently saved papers dekho — kahan tak kaam hua yaad aata hai
  • Quick search bar se directly affective computing topics search karo bina Explore page khole
  • Stats cards se andaza lagao kitne papers save karne baaki hain

Explore

/explore
4 academic databases (arXiv, Semantic Scholar, CrossRef, PubMed) mein ek saath search karo aur papers library mein save karo.

Search Features

  • Multi-source parallel search
  • Source filter: arXiv / Semantic Scholar / CrossRef / PubMed / All
  • Year filter: 2024, 2023... ya Before 2018
  • Result limit: 10–50 papers
  • Save search query for future use

Paper Card Actions

  • 🔖 Bookmark — Library mein save karo
  • 🔗 External link — Original paper open karo
  • Source badge (arXiv, PubMed etc.)
  • Publication year
  • Abstract preview
⚠️ Zaroori: Yahan sirf papers dhundhte hain — actually use karne ke liye pehle Library mein save karna zaroori hai. AI Assistant aur Analysis tabhi kaam karenge.

✅ Best Use Tips

  • Specific keywords use karo — "facial action unit CNN 2023" zyada accurate results deta hai "emotions" se
  • Ek search ko "Save Search" karo taaki baar baar type na karna pade
  • Source filter lagao: arXiv mein latest preprints milte hain, PubMed mein medical/psychology wale
  • Kam se kam 10-15 papers save karo tab Recommendations aur Analysis useful banenge

Library

/library
Aapki personal research repository — saved papers, uploaded PDFs, aur in-document search teen tabs mein.

Tab 1 — Saved Papers

  • Explore se save kiye papers
  • Tags add/remove karo per paper
  • External URL open karo
  • Paper library se hata do

Tab 2 — Uploads

  • PDF drag-drop ya click-to-upload
  • Processing status (pending → completed)
  • PDF inline preview (sidebar)
  • "Analyse" button → Document Analysis page

Tab 3 — Search Documents

  • Uploaded PDFs ke andar text search
  • Matching excerpts with page numbers
  • Match count per document

Tags System

deep-learning emotion survey dataset

Papers pe custom tags lagao — baad mein filter karne mein help karta hai

✅ Best Use Tips

  • PDF upload karne ke baad 10-30 sec wait karo — status "completed" ho tab Analyse button kaam karta hai
  • Tags system use karo: "chapter-2", "read", "important" — papers organized rehte hain
  • Search Documents tab se apne uploaded PDFs mein koi specific term dhundh sakte ho (e.g. "LSTM" ya "dataset size")

Analysis

/analysis
Saved papers ke trends, keyword distribution, aur research gaps AI se automatically identify karo.

Charts Tab

  • Publications by Year (line chart)
  • Research Domains (pie chart)
  • Top Keywords (bar chart)
  • Academic Sources breakdown
  • Year range + source filters
  • Keyword frequency cloud

Research Gaps Tab

  • Limitation patterns in papers
  • Underrepresented topics
  • Methodology gaps
  • Emerging topics
  • Evidence strength (Strong/Moderate/Emerging)
  • Supporting paper excerpts
⚠️ Zaroori: Analysis tab useful tabhi hoga jab Library mein kam se kam 5-10 papers saved hon. Khaali library mein sirf empty charts dikhenge.

✅ Best Use Tips

  • Research Gaps tab mein jo gaps milein — unhe AI Assistant mein question ki tarah pucho
  • Year filter se dekho 2020-2024 ke papers mein kon se topics trending hain
  • Keyword cloud se dissertation ke keywords/themes identify karo
  • "Rebuild Index" button tab dabaao jab naye papers save kiye hon aur gaps update nahi hue

AI Research Assistant

/assistant
Ollama AI (llama3.2) se apne saved papers ke baare mein questions pucho — citations ke saath jawab milte hain.

Chat Features

  • Multi-turn conversation (context yaad rehta hai)
  • Paper citations in responses ([1], [2])
  • Suggested starter questions
  • Conversation history load karo
  • New chat start karo
  • Old conversations delete karo

Research Context Panel

  • Library ke papers checkbox se select karo
  • AI sirf selected papers se answer deta hai
  • Specific paper ke baare mein pucho
  • Ollama status indicator (connected/offline)

🔮 Powerful Questions Examples

  • "What methodologies are most common in these papers?"
  • "What datasets are used for emotion recognition?"
  • "What are the limitations mentioned in these studies?"
  • "Compare the approaches of these two papers"
  • "What future research directions are suggested?"

✅ Best Use Tips

  • Context Panel mein specific papers select karo — zyada focused jawab milega
  • Response aane mein 30-60 sec lagta hai (local AI) — patience rakho
  • Ek conversation mein topic change mat karo — naya chat start karo
  • Citations wale papers ko Library mein check karo — original padhne ke kaam aate hain

Collections

/collections
Papers ko topic-wise groups mein organize karo aur har collection ka separately AI analysis karo.

Collection Management

  • New collection banao (name + description)
  • Color coding per collection
  • Paper count badge
  • Collection delete karo

Collection Detail

  • Papers tab — papers add/remove karo
  • Analysis tab — collection-specific gap analysis
  • Library se papers add karo (dropdown)
  • Analysis refresh karo

📌 Collection Ideas for Research

  • "Chapter 2 — Literature Review" → saare survey papers
  • "Facial Expression Recognition" → topic-specific papers
  • "To Read Later" → pending papers
  • "High Priority" → most relevant papers

✅ Best Use Tips

  • Dissertation chapters ke hisaab se collections banao — organized rehta hai
  • Analysis tab mein collection-specific gaps milte hain — chapter-level research gap identify hoti hai
  • Ek paper multiple collections mein ho sakta hai

Recommendations

/recommendations
Aapki library dekh ke AI similar papers suggest karta hai jo aapne miss kiye honge — match % ke saath.

What You See

  • Paper title + authors
  • Match % score (e.g. 87% match)
  • Reason: "Shares keywords: CNN, emotion"
  • Source + publication year
  • External link to paper

Actions

  • Save — directly library mein add karo
  • External link — original paper dekho
  • Already saved = green "Saved" badge
⚠️ Zaroori: Library mein kam se kam 3-5 papers hone chahiye recommendations dekhne ke liye. Naye account pe empty rahega.

✅ Best Use Tips

  • High match % wale papers pehle dekho — sabse relevant honge
  • Reason text padhne se samajh aata hai kyun suggest kiya — ignore mat karo
  • Zyada papers save karoge → Recommendations better hongi (algorithm Jaccard similarity use karta hai)

Reports

/reports
Research analysis ke exportable reports generate karo — PDF, DOCX, CSV, BibTeX formats mein.

Report Types

  • 📊 Library Summary — saari saved papers ka overview
  • 📈 Trend Analysis — publication trends over years
  • ⚖️ Paper Comparison — multiple papers compare

Export Formats

  • PDF — professional document
  • DOCX — Word mein edit ho sake
  • CSV — spreadsheet analysis
  • JSON — programmatic use
  • BibTeX — citation managers (Zotero/Mendeley)

✅ Best Use Tips

  • BibTeX format download karo — Zotero/Overleaf/LaTeX mein directly import ho jaata hai
  • Supervisor ko Library Summary PDF bhejna ho toh yahan se generate karo
  • CSV download karo — Excel mein khud se charts bana sakte ho
  • Report generate hone mein 10-30 sec lagta hai — status "Ready" hone ka wait karo

Comparison

/comparison
2 se 4 papers ko AI embeddings se semantically compare karo — similarity scores aur evidence excerpts ke saath.

How It Works

  • Library se 2–4 papers select karo (checkboxes)
  • "Compare" button dabao
  • AI FAISS similarity calculate karta hai
  • Individual relevance score milta hai
  • Pairwise comparison table

Results

  • Per-paper relevance % + label (High/Moderate/Low)
  • Progress bar visualization
  • Paper A vs Paper B similarity score
  • Evidence excerpts from both
  • External links

✅ Best Use Tips

  • Dissertation mein cite karne wale papers compare karo — high similarity = overlapping content, cite karna zaroori
  • Do methodologies compare karo (e.g. CNN paper vs Transformer paper) — differences identify hote hain
  • Low similarity (under 40%) = papers alag domains cover karte hain — broader literature review ke liye better

Document Analysis

/document-analysis/:id
Uploaded PDF ka deep analysis — keywords, page distribution, sections, aur key sentences charts ke saath.

Stats Cards

  • Total pages
  • Total word count
  • Text chunks count
  • Unique keywords

Charts

  • Top Keywords bar chart
  • Section Distribution pie chart
  • Words per Page line chart
  • Chunks per Page bar chart

Keyword Cloud

  • Scalable keyword tags
  • Frequency counts

Key Sentences

  • Most information-dense sentences
  • Page number + section badges
  • Color-coded by position
⚠️ Kaise Pahunche: Library → Uploads tab → Completed document → "Analyse" button click karo.

✅ Best Use Tips

  • Key Sentences section — paper ka quick summary samjhne ke liye best, poora padhne ki zaroorat nahi
  • Words per Page chart se dense sections identify karo (methodology/results wale pages zyada words wale hote hain)
  • Keyword cloud se apne research keywords validate karo — paper mein actually kaun se terms prominent hain
